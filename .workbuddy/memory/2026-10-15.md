## 方案 B 首次 make 报错修复（include 路径）

## 方案 B 链接期三错修复（v8 API + brotli + libm 顺序）
- 用户补了 brotli 库后再 `make`，链接期三错：
  1. `undefined reference to lv_font_add`：**根因=用了 v9 API**。v8.3.11 全树 grep `lv_font_add`=0，`lv_font_t` 仅含 `const fallback` 字段、无 setter；官方 v8.3.11 freetype 示例 `examples/libs/freetype/lv_example_freetype_1.c` 不用 `lv_font_add`，而是把 freetype 字体直接设到 style/label。
  2. `BrotliDecoderDecompress`：Debian `libfreetype.a` 编译开了 brotli/woff2 → 硬依赖 brotli。已确认 `libbrotlicommon.a`+`libbrotlidec.a` 就位。
  3. `pow`/`floor`：`libpng16.a` 引用，但 `-lm` 排在 `-lpng16` **前面**；静态库顺序敏感，数学库须放最后。
- 修复四处：
  1. `main.c`：加全局 `void * g_cjk_font = NULL;`（用 void* 因 lv_conf.h 早于 lv_font_t 被解析）；`init_cjk_font()` 去掉 `lv_font_add`，改为 `info.font->fallback = &lv_font_montserrat_14; g_cjk_font = (void*)info.font;`（freetype 主字体+montserrat 回退）；并把 `lv_ft_info_t info` 改为 `static` 以零初始化 `info.mem`（否则野指针走内存字体模式会崩/失败）。
  2. `lv_conf.h`：原 `#define LV_FONT_DEFAULT &lv_font_montserrat_14` 改为运行时切换宏 `extern void * g_cjk_font; #define LV_FONT_DEFAULT ((lv_font_t*)(g_cjk_font ? g_cjk_font : (void*)&lv_font_montserrat_14))`；确认 LV_FONT_DEFAULT 在 lvgl src 仅用于运行时赋值（非常量初始化），三元安全。
  3. `network_demo.c:342`：日志标签字体由 `&lv_font_montserrat_14` 改为 `LV_FONT_DEFAULT`（否则中文日志不走 freetype 字体）；title/hint 本就走 LV_FONT_DEFAULT，自动生效。
  4. `Makefile`：LIBS 重排为 `-lfreetype -lpng16 -lz -lbrotlidec -lbrotlicommon -lm`（-lm 最后；brotli 在后因 freetype 引用它）。

## Network demo 多次点击"卡死"修复（看门狗 + detach + 2s 超时）
- 用户报"多次点击 DNS 测试按钮会卡死"。先排除日志变量越界（`g_log_buf[2048]` + `strncat` 长度算得刚好，不会越界）。
- 截图定位：卡在 `try_connect` 的 `connect+select`，**不是 getaddrinfo**（因为 `[DNS] 解析到以下地址` 已打印）。根因：`select` 5 秒超时 + 期间 `g_running=1` 吞掉所有后续点击 → 体感卡死；若退出界面 `close()` 再 `pthread_join` 一个卡住线程 → 整个 app 冻结。
- 修复（network_demo.c）：① `select` 超时 5s→2s；② 加 `[CONNECT] 正在连接…` 进度提示；③ **看门狗**：`refresh_timer_cb` 里若 `g_running && lv_tick_get()-g_test_start_ms > 4000ms` 则强制 `g_running=0`（用 `g_epoch/g_running_epoch` 保证只清当前测试，防旧线程误清）；④ 后台线程改 **DETACHED**（`pthread_attr_setdetachstate`），`close()` 不再 `pthread_join`（避免 join 卡死线程冻住 app）；⑤ `open()` 末尾 `g_epoch++` 使上一屏遗留 detached 线程无法误清本屏标志。`g_tid` 全局变量已删除。
- 沙箱无 ARM 工具链，未实编；待用户在主机 `make all` 验证。
