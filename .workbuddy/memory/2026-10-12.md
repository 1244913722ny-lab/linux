## Makefile 链接报错修复（build/bin 不存在）
- 用户实编时报 `ld: cannot open output file build/bin/lvgl_demo: No such file or directory`。
- 根因：当前 Makefile（用户已改动过变量名为 BUILD_DIR/BUILD_DIR_OUT/BUILD_DIR_BIN）中 `$(BUILD_DIR_BIN)`（build/bin）**无创建规则**，且链接目标 `$(TARGET)` 只依赖 `$(OBJS)`，导致 build/bin 从未被建立、链接时目录缺失。源文件本身已能编译通过（报错发生在 ld 阶段）。
- 修复：新增 `$(BUILD_DIR_BIN): | $(BUILD_DIR)` 规则（mkdir -p $@），并把 `$(TARGET): $(OBJS) | $(BUILD_DIR_BIN)` 改为 order-only 依赖，保证并行 make 下链接前 build/bin 一定存在。对象规则已自带 `mkdir -p $(dir $@)` 建 build/out，无需再改。链接后追加 `chmod +x $@` 以免缺可执行位。

## 运行 ./lvgl_demo 报 "line 2: syntax error: unexpected (" 的真相
- 该报错是**假象**：bash 在 `execve` 返回 ENOEXEC 时会退化成把文件当 shell 脚本逐行解释，于是报语法错误。根因是**架构不匹配**——`build/bin/lvgl_demo` 与 `uboot-start/lvgl_demo` 经 ELF 头确认是 **x86-64**（e_machine=0x3E，链接 /lib64/ld-linux-x86-64.so.2），而用户实际目标机是 ARM（uboot-start 里有 u-boot/zImage/vexpress-v2p-ca9.dtb/full_sd.img 等 QEMU vexpress CA9 产物）。在 ARM 上跑 x86-64 ELF → ENOEXEC → 触发该错误。
- 结论：用户此前大概率是 `make CC=gcc` 编出了 x86-64。正确做法是用默认 `arm-linux-gnueabihf-gcc` 重编（`make clean && make`），`file` 确认出现 "ARM"，再拷进 uboot-start 并 `chmod +x`、打进 SD 镜像/板子根文件系统后在 ARM 侧运行。
- 两个 lvgl_demo 文件权限均为 `-rw-r--r--`，无可执行位，本机跑也会先 Permission denied，需 chmod +x。

## 修复 QEMU 中 LVGL 不能鼠标点击
- 现象：QEMU 里 LVGL 界面正常显示，但点击按钮无反应。
- 根因：
  1. `start_uboot.sh` 没有 `-usb`/`-device usb-tablet`，guest Linux 里根本没有 `/dev/input/event*` 鼠标节点。
  2. 原有 `lv_fb_drv.c` 的 EVDEV 驱动只处理 `EV_ABS`（触摸屏），而 QEMU USB 鼠标产生的是 `EV_REL`（相对坐标），即使设备存在也读不到坐标。
  3. `lv_evdev_init` 原来只打开固定的 `/dev/input/event0`，不会自动探测；且没有可见光标，用户不知道 LVGL 的 pointer 在哪。
- 修复：
  - `lv_fb_drv.c`：同时支持 `EV_ABS` 与 `EV_REL`；用 `EVIOCGBIT` 自动探测第一个可用的 pointer 设备（`event0`~`event31`）；鼠标初始坐标放到屏幕中心；用户空间自己实现位运算宏 `EV_BIT_ISSET`，避免依赖 `<linux/input.h>` 的 `test_bit`。
  - `lv_fb_drv.h`：`lv_evdev_init` 返回 `struct _lv_indev_t *`，方便主程序设置光标。
  - `main.c`：调用 `lv_evdev_init(NULL)` 自动探测；若成功则创建一个红色 12x12 小方块作为鼠标光标，调用 `lv_indev_set_cursor` 绑定。
- **关键修正：vexpress-a9 没有 USB 总线**（QEMU 机器模型无 PCI/USB 控制器），不能加 `-device usb-tablet`（报 `No 'usb-bus' bus found`）。已撤销该参数。该机器默认只有 PL050 KMI 的 PS/2 键盘/鼠标（相对坐标）。
- 新增键盘 keypad indev 作为最可靠输入：`lv_fb_drv.c` 增加 `lv_keyboard_init()`，用 `EVIOCGBIT(EV_KEY)` 探测键盘设备（支持 KEY_ENTER 且非 pointer），read_cb 映射 KEY_ENTER→LV_KEY_ENTER 等；`main.c` 创建 `lv_group`、把按钮加入并 `lv_indev_set_group(kbd, group)`，回车即触发按钮 CLICKED。`lv_fb_drv.h` 也声明了该接口，并给非 Linux 平台补 fallback。
- 局限：本沙箱无 make/交叉编译器，未实编；符号均已对照 v8.3.11 核实。QEMU 实际能否出现 event 节点取决于 guest 内核是否配置 serio/atkbd（键盘）与 PS/2 鼠标驱动；`ls /dev/input/` 为空时需重编内核开启对应输入驱动。
