## 桌面新增 FLIP 动效 demo（First-Last-Invert-Play）
- 用户要求在 LVGL 桌面启动器再加一个 demo，用 **FLIP 算法**做重排动效。
- 新增文件 `app/flip_demo.c` + `app/flip_demo.h`，接口沿用 network_demo：`flip_demo_open()`/`flip_demo_close()`，在 `lv_scr_act()` 上建 UI、`close` 里 `lv_obj_clean(lv_scr_act())`。
- FLIP 实现要点（v8 无 transform_x/y，故用**绝对坐标 + lv_anim 驱动 x/y**）：
  - 8 张彩色卡片(4×2)，棋盘容器默认 flow=NONE，卡片用 `set_x/set_y` 绝对摆放，避免布局覆盖动画坐标。
  - 洗牌 `flip_shuffle()`：Fisher-Yates 排列 → 对每张卡**先 `lv_obj_get_x/y` 取当前真实坐标作 First**（即使上轮动画未完也安全，因 `lv_anim_start` 自动顶掉旧动画）→ 计算目标槽位作 Last → 用 `lv_anim`(0→1024, ease_out, 450ms) 从 First 滑到 Last(Play)。
  - 动画 exec `flip_exec()`：线性插值 x/y；中段给 `transform_zoom` 缩放凹陷(整数抛物线 256→192→256)增强"抬起→落下"视感。
  - 「洗牌」按钮单次触发；「自动」按钮用 `lv_timer_create`(1200ms) 循环洗牌，close 时 `lv_timer_del`。
- 注册：main.c `#include "flip_demo.h"` + `g_demos[]` 末尾加 `{"FLIP", LV_SYMBOL_SHUFFLE, 0x22C55E, flip_demo_open, flip_demo_close}`；Makefile `APP_SRCS` 加 `flip_demo.c`。
- 连带修复：第 7 个磁贴使桌面容器 3 行溢出(原 6 个正好 3×2)，给 `build_desktop()` 的磁贴容器加 `lv_obj_set_scroll_dir(cont, LV_DIR_VER)` + `lv_obj_set_scrollbar_mode(cont, LV_SCROLLBAR_MODE_AUTO)`，溢出部分可纵向滚动不裁切。
- API 核对(v8.3.11)：`lv_anim_exec_xcb_t=void(*)(void*,int32_t)`、`lv_anim_set_var/exec_cb/values/time/path_cb`、`lv_anim_path_ease_out`、`lv_obj_get/set_x/y`、`lv_obj_get/set_user_data`、`lv_obj_set_style_transform_zoom`、`lv_obj_set_scroll_dir`、`lv_timer_create/del`、`LV_SYMBOL_SHUFFLE` 均存在；**`LV_OPA_100` 不存在**，卡片不透明度改用 `LV_OPA_COVER`。
